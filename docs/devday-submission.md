# Rosca Kombat — ficha para DevDay

**Nombre:** Rosca Kombat

**Versión:** 1.2.0

**Plataforma:** Game Boy Color / ModRetro Chromatic

**Licencia:** MIT para el código y los recursos originales; avisos de componentes de terceros incluidos.

**Descripción corta (ES):** Un arcade satírico de pelea con 32 caricaturas de la política argentina, poderes absurdos y cuatro escenarios reconocibles. 32 egos, una silla.

**Short description (EN):** A satirical Game Boy Color fighting game featuring 32 Argentine political caricatures, absurd special moves, and four Buenos Aires stages. 32 egos, one seat.

**Descripción:** Creado con Codex como una ROM original de 256 KiB. Incluye selección de luchador y rival, combates contra la CPU al mejor de tres rounds, tres dificultades, torneo de ocho peleas, seis familias de poderes, música y remates de caricatura sin gore. Los 32 retratos son nativos de 64×80 píxeles; los luchadores usan cabezas de 32×32 con seis poses. Escenarios: Congreso, Casa Rosada, Obelisco y una obra en construcción. El código C, los generadores de arte y las pruebas están disponibles para estudiar, compilar y modificar el juego.

**Controles:** cruceta para caminar/saltar/bloquear; A golpe; B patada; SELECT especial; A+B súper; START pausa.

**ROM:** `build/rosca-kombat.gbc`

**SHA256:** `cea93cb8113614e37bae783fb90dd14a106f871253802274c34e6812b5353ca8`

**Captura principal:** `build/arena-redesign-1.png`

**Plantel:** `build/roster-gallery.png`

**Validación:** 90 comprobaciones de juego y 803 de gráficos en la ROM compilada. La CLI oficial confirmó la transmisión USB al Chromatic en estado `running`.

**Arte:** ilustraciones generadas con imagegen y convertidas al formato de tiles y paletas de CGB; originales y prompts incluidos. Escenarios, cuerpos y poses definidos mediante generadores del proyecto. Música y efectos propios. Sin gráficos, audio ni código de Mortal Kombat.

**Publicación en DevDay:** pendiente de identificar un canal de envío que permita incorporar el juego. La galería pública `https://developers.openai.com/modretro` no mostró un formulario de publicación durante la revisión; esta ficha no implica que el juego esté publicado allí.
